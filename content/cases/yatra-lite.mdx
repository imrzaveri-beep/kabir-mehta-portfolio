## Problem

A travel idea can happen anywhere, including on a train with an unreliable connection. This fictional PWA concept starts from that constraint: visitors need useful trip information before decorative content finishes loading.

The aim was to make discovering and comparing stays feel light without stripping away the joy of planning.

## Research

The demo research plan tests the key jobs on low-end phones and limited networks: find a destination, compare a stay and return to a saved option. It prioritises readable content, clear loading states and recovery after a connection drops.

These are proposed evaluation conditions, not a claim that a production travel product was tested.

## Ideation

I compared image-heavy discovery, text-first search and a compact editorial collection. The final concept combines a focused destination card with short, useful details. Secondary media follows the essential content.

An information budget for each screen helped remove repeated details and reserve attention for the next decision.

## Design

The concept uses small reusable components, predictable aspect ratios and restrained visual effects. Destination cards expose location, stay type and the action clearly. Loading and unavailable states use the same layout to reduce disruptive shifts.

The original mockups are static illustrations. No bookings, accounts, offline travel database or payments are implemented by this portfolio.

## Results

The supplied fictional metric is **1.2 seconds for the first load on 3G**. It describes the concept in the brief, not this portfolio’s measured load time. A real performance claim needs a device, network profile and a clearly named metric.

The proposed evaluation combines loading performance with task completion, so a lightweight screen still has to be useful.

## Key learnings

- Start with the slowest connection you need to support.
- Reserve space before content arrives.
- A smaller payload cannot compensate for unclear choices.
- Always name the metric behind a performance claim.
